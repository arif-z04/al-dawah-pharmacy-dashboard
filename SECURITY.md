## Reporting a Vulnerability

The safety and privacy of pharmaceutical inventory and patient records is paramount.

If you discover a security vulnerability in **Al-Dawah Pharma**, please **do not open a public issue**. Instead, follow responsible disclosure:

1. Send an email with details of the vulnerability, reproduction steps, and potential impact to the repository maintainers.
2. Please include:
   - Type of issue (e.g., SQL injection, authentication bypass, CSRF, privilege escalation).
   - Component affected (Oracle PL/SQL trigger, Web API controller, frontend client).
   - Proof of Concept (PoC) code or requests.
3. We will acknowledge receipt within 48 hours and work with you to test and release a patch before public disclosure.
